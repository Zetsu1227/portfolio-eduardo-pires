# 🧩 < Desenvolvimento de Software >
**Período:** 2026/1  
**Projeto:** MIDI Converter  
**Professor:** Marcelo Pimenta

---

## 🎯 Problema a ser resolvido
Desenvolver uma aplicação capaz de converter um texto estruturado em um arquivo MIDI, onde cada linha representa uma voz (instrumento) independente. A partir de uma linguagem textual definida pelo projeto, o sistema interpreta os caracteres digitados pelo usuário e os transforma em notas musicais, pausas, duração e demais eventos musicais, gerando automaticamente uma composição em formato MIDI.

Além da implementação da funcionalidade principal, o projeto teve como foco aplicar princípios de Engenharia de Software, priorizando qualidade de código, modularização, refatoração, testes e desenvolvimento colaborativo.

---

## 🏗️ Arquitetura e Tecnologias

- Pyhton, utilizando Programação Orientada a Objetos.
- Arquitetura modular, separando parser, regras de conversão e geração do arquivo MIDI.
- Controle de versão com Git para desenvolvimento colaborativo.
- Organização do projeto em módulos independentes, facilitando manutenção e evolução do código.

---

## 🧱 Boas práticas aplicadas

- Aplicação dos princípios de modularidade, encapsulamento e baixa dependência entre componentes.
- Refatoração contínua para reduzir code smells e melhorar a legibilidade do código.
- Revisão de código, padronização de nomenclatura e documentação para facilitar o trabalho em equipe.
  
---

## 🤝 Soft Skills

- Comunicação e colaboração em equipe durante o desenvolvimento em grupo.
- Organização das tarefas utilizando versionamento e divisão de responsabilidades entre os integrantes.

## 📈 Resultados e Aprendizados
- O que funcionou bem:  
  1. A arquitetura modular facilitou a implementação de novas funcionalidades e futuras alterações nas regras de conversão.
  2. O uso de Git permitiu integrar o trabalho dos quatro integrantes com maior organização e controle das mudanças.
  
- O que poderia melhorar:
  1. Implementar uma suíte mais completa de testes automatizados para validar diferentes entradas e cenários.
  
- Conceitos mais aplicados da disciplina:  
  1. Programação Orientada a Objetos, abstração e encapsulamento.
  2. Modularidade, refatoração e identificação de code smells.
  3. Controle de versão, revisão de código e boas práticas de desenvolvimento de software.

- Lições para projetos futuros:  
  1. Investir na definição da arquitetura antes do início da implementação reduz significativamente o retrabalho durante o desenvolvimento.
  2. Manter padrões de código, documentação e revisões frequentes melhora a qualidade do software e facilita o trabalho colaborativo.
