# 🧩 < Banco de Dados >
**Período:** 2026/2  
**Projeto:** Data-System-Youtube  
**Professor:** Karin Becker

---

## 🎯 Problema a ser resolvido
O trabalho prático proposto para os alunos abrangia o projeto lógico de um sistema baseado em uma base de 
dados existente no nosso dia a dia. Nesse sentido, eu e minha dupla escolhemos o Youtube por ter vários elementos
para utilizar de tabelas SQL. Assim, foi pedido a nós a elaboração de consultas em SQL e a implementação de um programa
que acessa a base através de recursos do SGBD.

---

## 🏗️ Arquitetura e Tecnologias

- PostgreSQL / SQLite como opções para manipular banco de dados
- Python para fazer programa integrado com linguagens SQL
- VS Code como ambiente de desenvolvimento 
- GitHub Desktop para facilitar a manipulação de versões do projeto

## 📈 Resultados e Aprendizados
- O que funcionou bem:  
  1. A adoção de um plano de sistema com um diagrama de classes otimizou o desenvolvimento do projeto.
  2. O uso do GitHub Desktop para controle de versões permitiu acompanhar a evolução do projeto, testar alterações de forma segura e recuperar versões anteriores quando necessário.
  
- O que poderia melhorar:
  1. A criação de mais visões para subconsultas muito utilizadas ajudaria a otimizar o tempo de processamento do programa.
  2. A interface foi feita no terminal, poderia utilizar o Pygame ou até o Vercel para deixar uma interface mais bonita.
  
- Conceitos mais aplicados da disciplina:  
  1. SQL - criação e manipulação de banco de dados.
  2. Modelos relacionais e normalização.
  3. Transações e Controle de Concorrência.

- Lições para projetos futuros:  
  1. Avaliar previamente diferentes tabelas e quais seriam ideias para representar sistemas muito elaborados.
  2. Continuar priorizando legibilidade e documentação, especialmente pensando em projetos colaborativos ou de longo prazo.
